# .designbook/

Everything this project's design board shows. The board itself is the `.designbook` file
beside this folder: open it in VS Code and the board opens.

This file is facts, not rules: what is on the board, the files behind it, and what this
project actually uses. It is rewritten by the board whenever the project changes, so
nothing here is worth editing by hand.

The rules for working on it are in the repo's own `CLAUDE.md` and in the `design-book`
skill, which loads itself when there is designing to do.
